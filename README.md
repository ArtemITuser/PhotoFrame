# 📷 PhotoFrame v1.2.2.0 — Цифровая Фоторамка для Windows

## Полнофункциональное WPF-приложение для просмотра фотографий в режиме цифровой фоторамки. Оптимизировано для сенсорного управления и мыши.
#### * **arm64 билды будут собираться позднее, сейчас на arm64 всё работает через Houdini. Под arm32 Windows 10 (build 15035 etc, например на Surface RT) вероятность запустить фото рамку низкая, поэтому в данный момент эта архитектура не поддерживается.*
* *Windows 10 – среда, где Photoframe WPF работает стабильно. При этом, при экспериментах мне также удалось запустить последние версии Фоторамки на ПК Windows 7, 775 сокет, 5 Гб ОЗУ. Система сборки 6.1.7601 со всеми обновлениями до 2020, обновлениями ESU до 2023 и патчами безопасности 2026.*

## Управление

### Клавиатура

| Клавиша | Действие |
|---|---|
| `→` `↓` PageDown | Следующее фото |
| `←` `↑` PageUp | Предыдущее фото |
| Пробел | Пауза / Пуск |
| `F` или `F11` | Полный экран |
| `Escape` | Выход из полного экрана / Закрыть |
| `Ctrl+,` | Открыть настройки |

### Мышь

| Действие | Результат |
|---|---|
| Клик в правой половине | Следующее фото |
| Клик в левой половине | Предыдущее фото |
| Двойной клик | Полный экран ↔ Оконный режим |
| Движение мыши | Показать тулбар |

### Тач-жесты

| Жест | Действие |
|---|---|
| Свайп влево | Следующее фото |
| Свайп вправо | Предыдущее фото |

## Тулбар (нижняя панель)

| Кнопка | Описание |
|---|---|
| ⇄ (режим) | Переключить режим: перемешать / по порядку / случайно / по дате |
| − / + | Уменьшить / увеличить интервал |
| ◀ | Предыдущее фото |
| ▶ / ⏸ | Пуск / Пауза |
| ▶ | Следующее фото |
| ☀ / ☾ | Сменить тему |
| ⚙ | Открыть настройки |
| ⛶ / ⊡ | Полный экран / Оконный режим |

В полноэкранном режиме тулбар автоматически скрывается через 3 секунды
бездействия и появляется при движении мыши.

## Настройки

Настройки сохраняются в `%AppData%\PhotoFrame\settings.json`.

### Основное
- Интервал смены фото (1 с — 3600 с)
- Автозапуск слайдшоу при старте
- Зациклить воспроизведение
- Включать подпапки

### Источники фотографий
- Добавить папку (диалог выбора)
- Добавить диск (весь логический том)
- Предпросмотр миниатюр выбранных папок
- Поддерживаемые форматы: JPG, PNG, BMP, GIF, TIFF, WebP

### Оверлеи
- Директория файла — левый верхний угол
- Дата съёмки из EXIF — правый нижний угол
- GPS-координаты из EXIF — верх по центру
- Настройка размера шрифта

### Воспроизведение
Режимы порядка:
- **По порядку** — по имени файла
- **Перемешать** — shuffle без повторов, при повторном цикле перетасовывается
- **Случайно** — TrueRandom, каждый раз без запоминания предыдущего
- **По дате ↑ / ↓** — из EXIF DateTaken

Переходы (20 типов):
Fade · Slide (×4) · Zoom In/Out · Flip H/V · BlurDissolve ·
Wipe (×4) · Checkerboard · **Ken Burns** · **Mosaic** · **Spiral** · **PageTurn**

### Внешний вид
- Тема: Системная / Тёмная / Светлая
Fluent:
- Эффект Mica (только Windows 11, сборка 22000+)
- Acrylic Blur (Windows 10)
- Базовая прозрачность также может работать на Windows 7, но нестабильно. Также возможны проблемы с переключением темы на Windows 7, поэтому рекомендуется Windows 10 (10240.0+)

### Система
- Автозагрузка при входе в Windows (HKCU\...\Run)
- Сворачивание в трей
- Регистрация как системный скринсейвер (`.scr`)
  - Запуск как скринсейвер: `PhotoFrame.exe /s`
  - Открыть только настройки: `PhotoFrame.exe /c`
- Задержка активации скринсейвера

### Питание
- Запрет перехода в режим сна (`SetThreadExecutionState`)
- Тайм-аут отключения монитора
- Тайм-аут перехода в сон

## Иконки

Тулбар использует глифы **Segoe MDL2 Assets** (встроен в Windows 10+).
Это устраняет зависимость от внешних файлов PNG и обеспечивает корректное
масштабирование на любом DPI. Файлы Aero PNG из архива встроены в сборку
и доступны для расширения.

## Системная интеграция — скринсейвер

```
PhotoFrame.exe /s    — полноэкранный режим скринсейвера
PhotoFrame.exe /c    — открыть только настройки
PhotoFrame.exe /p    — предпросмотр (minipreview, для Control Panel)
```

Для регистрации в системе используйте кнопку в Настройки → Система.
При первом запуске может потребоваться разрешение UAC.
